# Cyber Game

A tycoon-style cybersecurity simulator for the browser. Start in your garage, upgrade PCs and server racks, buy security tools, hire pen testers, and grow your operation.

## Status

Early prototype. Not playable yet.

## Planned tech

- [Phaser 3](https://phaser.io/) game engine
- Vite for local development and minified builds
- Hosted on GitHub Pages

## Workflow

- `main` is protected: every change lands through a pull request.
- No secrets in this repo. The game is a static site and needs no API keys.
